# Bếp Việt – Ứng dụng di động

Mã nguồn ứng dụng Expo / React Native của dự án **Bếp Việt**.

Xem hướng dẫn đầy đủ (tính năng, cài đặt, biến môi trường, API, triển khai) tại [README chính](../README.md).

```bash
npm install
cp .env.example .env   # đặt EXPO_PUBLIC_API_URL
npx expo start --dev-client
```
